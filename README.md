# gin
My Crappy Text Editor

- Fork and clone this project
- Make sure you have cc(C Compiler installed)
- If you do not like cc, make sure you modify the makefile to use your compiler of choice.
- run make to compile and make gin out of gin.c
- run ./gin to run the program.




- Remember, this is a crappy text editor. DO NOT HAVE HIGH HOPES! (Work In Progress)
